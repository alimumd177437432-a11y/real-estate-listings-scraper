# سكربت سحب إعلانات السيارات (لموقع نوق وسوق)

سكربت Node.js بيسحب 50 إعلان جديد (غير مكرر أبداً) من صفحة البحث بموقع
cars4sale.ps، وبيخزنهم بملف إكسل مع تحميل صورة كل إعلان محلياً.

## طريقة العمل بالمختصر

1. بيفتح متصفح Chrome مصغّر (Puppeteer) على صفحة البحث.
2. بيقرأ كل الإعلانات الظاهرة بالصفحة الحالية.
3. بيتجاهل أي إعلان سبق وانسحب (محفوظ بملف `data/seen.json`).
4. إذا لسا ما وصلنا 50 إعلان جديد، بينقر "التالي" وبيكرر.
5. بيحمّل صورة كل إعلان جديد لمجلد `images/`.
6. بيضيف كل الإعلانات الجديدة كصفوف بملف `output/listings.xlsx`
   (من غير ما يمسح الصفوف القديمة).
7. بيحدّث `data/seen.json` حتى ما ترجع تنسحب نفس الإعلانات بمرة جاية.

## خطوات التشغيل خطوة بخطوة

### 1) تأكد إنه Node.js مثبت عندك

```bash
node -v
```

لازم يكون عندك نسخة 18 أو أحدث. إذا مش مثبت، حمّله من nodejs.org.

### 2) ثبّت المكتبات المطلوبة

جوا مجلد المشروع:

```bash
npm install
```

هاد رح يثبت:
- **puppeteer** — لفتح متصفح حقيقي وتصفح الموقع (لأنه الترقيم بين
  الصفحات شغال بجافاسكريبت مش بروابط عادية).
- **exceljs** — لإنشاء/تعديل ملف الإكسل.
- **axios** — لتحميل صور الإعلانات.

> ملاحظة: أول مرة بتنزل puppeteer رح يحمّل نسخة Chromium كاملة
> (حوالي 200-300 ميجا)، فخليك صبور أول مرة بس.

### 3) شغّل السحب

```bash
npm run scrape
```

أو مباشرة:

```bash
node index.js
```

رح تشوف بالتيرمينال شي شبيه:

```
🚀 بدء عملية السحب من cars4sale.ps ...
ℹ️  عدد الإعلانات المسحوبة بمرات سابقة (رح نتجاهلها): 0
📄 صفحة 1: لقينا 20 إعلان بالصفحة، الجديد التراكمي: 20/50
📄 صفحة 2: لقينا 20 إعلان بالصفحة، الجديد التراكمي: 40/50
📄 صفحة 3: لقينا 20 إعلان بالصفحة، الجديد التراكمي: 50/50
📥 رح نحمّل صور 50 إعلان جديد، استنى شوي...
✅ تم بنجاح! انسحب 50 إعلان جديد وانضافوا لملف الإكسل.
```

### 4) كل مرة بدك تسحب فيها دفعة جديدة

بس شغّل نفس الأمر تاني:

```bash
node index.js
```

السكربت رح يتذكر تلقائياً كل الإعلانات اللي سحبها قبل (عن طريق ملف
`data/seen.json`) وما رح يكررهم أبداً، وبيكمل ياخد 50 إعلان **جديد**
مختلفين، ويزيدهم بنفس ملف `output/listings.xlsx`.

## هيكل الملفات

```
nawq-scraper/
├── config.js          ← كل الإعدادات (رابط الموقع، عدد الإعلانات...)
├── store.js           ← إدارة "ذاكرة" الإعلانات المسحوبة سابقاً
├── scraper.js          ← منطق فتح المتصفح واستخراج البيانات والتنقل بالصفحات
├── imageDownloader.js  ← تحميل صور الإعلانات
├── excelWriter.js      ← الكتابة/الإضافة لملف الإكسل
├── index.js            ← نقطة التشغيل الرئيسية
├── data/
│   └── seen.json       ← قائمة روابط الإعلانات المسحوبة (لا تحذفها!)
├── images/              ← الصور المحمّلة
└── output/
    └── listings.xlsx    ← الملف النهائي اللي بتفتحه بإكسل
```

## أهم الإعدادات القابلة للتعديل (بملف `config.js`)

| الإعداد | الوظيفة |
|---|---|
| `TARGET_COUNT` | كم إعلان جديد بدك كل مرة (افتراضي 50) |
| `HEADLESS` | خليها `false` مؤقتاً إذا بدك تشوف المتصفح شغال أمامك (مفيد للتشخيص) |
| `MAX_PAGES_TO_VISIT` | حد أقصى لعدد الصفحات يلي رح يتصفحها بمحاولة وحدة |
| `DELAY_BETWEEN_PAGES_MS` | مدة الانتظار بين كل صفحة وبين تشغيلة بدون ما نحمّل السيرفر |

## إذا الموقع غيّر تصميمه وتوقف السكربت عن العمل

استخراج البيانات مبني على **كلمات ونصوص ظاهرة** (زي أسماء المدن،
"₪"، "cc"، "فحص"...) مش على أسماء كلاسات CSS، فهو مرن نوعاً ما. لكن
إذا الموقع غيّر بنيته بشكل جذري:

1. افتح `config.js` وحط `HEADLESS: false` حتى تشوف المتصفح شغال
   قدامك عيني عينك.
2. شغّل `node index.js` وراقب شو عم يصير.
3. افتح الموقع بمتصفحك العادي، اضغط F12 (أدوات المطور)، وشوف الـ
   HTML الفعلي لبطاقة إعلان وحدة، وقلي شو تغيّر حتى أعدّل دالة
   `extractCurrentPageListings` بملف `scraper.js`.

## تنبيه مهم بخصوص الاستخدام

- هاد الكود بيسحب بيانات ظاهرة للعامة بصفحة البحث، وما بيسحب أي شي
  محمي بتسجيل دخول.
- الإعلانات هاي أصلاً ملك لأصحابها الأصليين (البائعين)، مش ملك
  cars4sale.ps ولا ملك موقعكم. لو ناوين تعرضوها لزوار موقعكم "نوق
  وسوق" كإعلانات حقيقية يقدروا يتواصلوا بخصوصها، لازم تاخدوا هاد
  بعين الاعتبار من ناحية قانونية وأخلاقية (حقوق النشر، خصوصية
  البائعين، شروط استخدام الموقع الأصلي).
- ماشي داعي تشغّل السكربت بشكل متكرر وسريع جداً (زي كل ثانية) حتى ما
  تحمّل سيرفر الموقع فوق طاقته - فيه تأخير مبني بالكود لهاد السبب.
